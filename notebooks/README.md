# Notebooks

탐색적 데이터 분석, 디버깅, 결과 해석용 노트북을 둔다.

이 디렉터리의 실제 notebook은 데이터와 출력이 포함될 수 있어 Git에서 제외한다. 공유할 가치가 있는 분석 로직은 `src/gtf/` 또는 재현 가능한 `experiments/` 스크립트로 옮기고, 정식 결과는 config와 run ID로 추적한다.

## 규칙

- `00_`, `01_` 같은 순번과 목적을 파일명에 포함한다.
- 핵심 알고리즘을 notebook에만 남기지 않고 안정화되면 `src/gtf/`로 이동한다.
- 대용량 출력과 데이터는 notebook에 embed하지 않는다.
- 정식 수치는 config 기반 실험으로 재생성하고 run ID를 적는다.
- 실행 순서가 위에서 아래로 재현되도록 정리한 뒤 커밋한다.
